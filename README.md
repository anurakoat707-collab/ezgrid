# EZGrid - ตารางคิดเลข

เลือกขนาดตารางเอง (1×1, 2×2, 3×3 ... หรือ 10×2, 5×4 ฯลฯ) · แต่ละแถวเลือก **+ − × ÷** · ผลอยู่ขวาสุด · รวมผลทุกแถวด้านล่าง

```
 #  คิด    A     B     C        ผล
 1 [ × ]  [20] [60] [ 2]   = 2,400
 2 [ − ]  [100][40] [  ]   =    60
 3 [ + ]  [ 5] [ 7] [ 3]   =    15
 ──────────────────────────────────────
 รวมผลทุกแถว  2,475      [+ แถว] [ตาราง 3×3]
```

แอปเว็บแบบติดตั้งได้ (PWA) ไม่ต้องลงโปรแกรม ไม่ใช้ไลบรารีภายนอก ใช้งานออฟไลน์ได้หลังเปิดครั้งแรก
ข้อมูลเก็บในเครื่อง (localStorage ของเบราว์เซอร์) ไม่ได้ส่งขึ้นเซิร์ฟเวอร์

## วิธีใช้

- **ขนาดตาราง** (ปุ่มขวาล่าง): แตะ/ลากบนตารางตัวอย่าง, ปุ่มลัด 1×1 ... 6×6, หรือ − / + (สูงสุด 200 แถว × 12 คอลัมน์)
- **ปุ่มสีฟ้าหน้าแถว** = เลือก + − × ÷ ของแถวนั้น (หรือ "ใช้กับทุกแถว") แถวนั้นจะคิดจากซ้ายไปขวา เช่น 20 × 60 × 2
- ช่องว่างข้ามไป ไม่นับ · หารด้วย 0 = ขึ้นข้อความเตือน ไม่นับในยอดรวม
- กด Enter = ไปช่องถัดไป (ช่องสุดท้ายของแถวสุดท้าย = เพิ่มแถวให้)
- **เลขแถว** = แทรกแถวด้านล่าง / ล้างแถว / ลบแถว (เลิกทำได้ 5 วินาที)
- **ปุ่มแชร์** = ส่งผลทั้งหมดเป็นข้อความ (LINE ฯลฯ) · แตะชื่อชุดด้านบน = มีหลายตาราง (ชุด) ได้

## ติดตั้งในมือถือ

ลิงก์: https://anurakoat707-collab.github.io/ezgrid/

- **Android:** เปิดใน **Chrome** → **⋮ → ติดตั้งแอป** (หรือ "เพิ่มลงในหน้าจอหลัก")
- **iPhone / iPad:** เปิดใน **Safari** → ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | ตัวแอปทั้งหมด |
