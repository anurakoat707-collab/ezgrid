# EZGrid Mobile

ตารางกรอกตัวเลขบนมือถือ ใช้ง่ายกว่า Excel - คิดได้แค่ **+ − × ÷** และ **รวมผล (Σ)**

แอปเว็บแบบติดตั้งได้ (PWA) ไม่ต้องลงโปรแกรม ไม่ใช้ไลบรารีภายนอก ใช้งานออฟไลน์ได้หลังเปิดครั้งแรก
ข้อมูลบันทึกในเครื่อง (localStorage ของเบราว์เซอร์) ไม่ได้ส่งขึ้นเซิร์ฟเวอร์

## ไฟล์ (วางรวมกันในโฟลเดอร์เดียว ห้ามมีโฟลเดอร์ย่อย)

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | ตัวแอปทั้งหมด |
| `manifest.webmanifest` | ชื่อแอป / ไอคอน สำหรับติดตั้ง |
| `sw.js` | เก็บไฟล์ไว้ใช้ออฟไลน์ (แก้ไฟล์ใดแล้ว ให้เปลี่ยน `VERSION`) |
| `icon-192.png`, `icon-512.png` | ไอคอนแอป |

## ติดตั้งในโทรศัพท์ Android

1. อัปโหลดทุกไฟล์ขึ้น GitHub (repo ใหม่ เช่น `ezgrid`) → **Settings → Pages** → *Deploy from a branch* → `main` / `(root)`
2. ในมือถือ เปิด **Chrome** ไปที่ `https://<ชื่อผู้ใช้>.github.io/ezgrid/`
3. กด **⋮ (มุมขวาบนของ Chrome) → ติดตั้งแอป** (หรือ "เพิ่มลงในหน้าจอหลัก")
   หรือในแอปกด **⋮ → 📲 ติดตั้งลงมือถือ**
4. ไอคอน **EZGrid** จะอยู่บนหน้าจอ เปิดเต็มจอเหมือนแอปทั่วไป ใช้ได้แม้ไม่มีเน็ต

**iPhone / iPad:** เปิดลิงก์ใน **Safari** → ปุ่มแชร์ (สี่เหลี่ยมมีลูกศรขึ้น) → **เพิ่มไปยังหน้าจอโฮม**

> ต้องเปิดผ่าน **https** (GitHub Pages ใช้ได้) - เปิดไฟล์จากเครื่องตรง ๆ หรือ http ธรรมดาจะติดตั้งไม่ได้

## วิธีใช้

1. แตะช่อง แล้วพิมพ์ตัวเลขที่แถบด้านล่าง
2. กด **→** (ไปขวา) หรือ **✓ ตกลง / ↓** (ไปช่องล่าง)
3. เมื่อมีตัวเลขติดกัน 2 ช่องขึ้นไป แถบคิดเลขจะขึ้นมาเอง พร้อมผลลัพธ์ให้ดูก่อนกด

   ```
   คิดเลข 20 ○ 60  → ใส่ที่ C1
   [ + = 80 ] [ − = -40 ] [ × = 1,200 ] [ ÷ = 0.3333 ] [ Σ = 80 ]
   ```

4. กดเครื่องหมายที่ต้องการ ผลจะลงช่องถัดไป (เป็นสูตร เช่น `=A1*B1` แก้ตัวเลขแล้วผลเปลี่ยนตาม)
5. **รวมผล:** แตะช่องว่างใต้คอลัมน์ผลลัพธ์ แล้วกด **Σ รวมผล**

อื่น ๆ

- **เลือกช่วง** (ปุ่มด้านบน) เลือกหลายแถวแล้วกดเครื่องหมาย = คิดให้ทุกแถว
- พิมพ์สูตรเองได้ เช่น `=(B2-C2)*2` ระหว่างพิมพ์ แตะช่องในตาราง = ใส่ตำแหน่งให้
- หัวตาราง A B C D ... / แถว 1 2 3 ... เลื่อนลงหรือเลื่อนขวาแล้วตารางเพิ่มให้เอง
- จัดรูปแบบ (ตัวหนา, สี, 1,234.00, ฿, %), หลายชีต, แทรก/ลบแถวและคอลัมน์, ย้อนกลับ, ส่งออก/นำเข้า CSV (เปิดใน Excel ได้)

## ทดสอบในเครื่อง

`php -S 127.0.0.1:8099 -t .` แล้วเปิด http://127.0.0.1:8099/ (localhost ติดตั้ง / ออฟไลน์ได้เหมือน https)
